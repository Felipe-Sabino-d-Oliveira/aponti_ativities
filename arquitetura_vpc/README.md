# Arquitetura Cloud Segura — AWS

Projeto acadêmico para a atividade “Projetar uma Arquitetura Cloud Segura”.

## Arquivos
- `arquitetura-cloud-segura.drawio`: diagrama editável no diagrams.net / extensão Draw.io do VS Code.
- `justificativa-tecnica.docx`: justificativa das decisões arquiteturais.
- `fluxos-de-comunicacao.md`: tabela de origens, destinos, protocolos, portas e regras de bloqueio.

## Abrir e exportar
1. Abra `arquitetura-cloud-segura.drawio` no VS Code com a extensão Draw.io, ou importe em https://app.diagrams.net/.
2. Revise o diagrama e ajuste os nomes/portas conforme as decisões do grupo.
3. Para gerar PDF do diagrama, use **File → Export as → PDF** no Draw.io.
4. Faça commit dos arquivos no GitHub e envie o link do repositório e o ZIP conforme solicitado pela atividade.

## Observação
É uma arquitetura de referência, não infraestrutura provisionada. Antes de apresentar, o grupo deve entender e conseguir justificar cada componente e fluxo.
